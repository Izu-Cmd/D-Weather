# D-Weather ☁️

A clean, modern weather app built with **vanilla HTML, CSS, and JavaScript** — no frameworks, no build step, no API keys.

## ✨ Features

- Search any city worldwide
- Real-time temperature, feels-like, humidity, and wind speed
- Open-Meteo weather codes translated to plain-English descriptions
- Mobile-friendly responsive layout
- Zero dependencies

## 🚀 Live Demo

Open `index.html` in your browser — that's it.

Or deploy for free on **GitHub Pages**, **Netlify**, or **Vercel**.

## 🛠️ Tech

- **HTML5** + **CSS3** (custom properties, flex/grid, no preprocessors)
- **JavaScript** (ES6+, async/await, Fetch API)
- **[Open-Meteo](https://open-meteo.com/)** for geocoding + weather data (free, no API key)

## 📦 Run Locally

```bash
git clone https://github.com/Izu-Cmd/D-Weather.git
cd D-Weather
open index.html   # macOS
xdg-open index.html   # Linux
start index.html   # Windows
```

## 🌐 Deploy to GitHub Pages

1. Push to GitHub (already done ✅)
2. Repo **Settings → Pages**
3. Source: **Deploy from a branch** → `main` / root
4. Your app will be live at `https://izu-cmd.github.io/D-Weather/`
